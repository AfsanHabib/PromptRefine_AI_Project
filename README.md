# 🚀 Prompt Optimizer Studio

An AI-powered prompt engineering workspace that analyzes, scores,
and transforms prompts using a hybrid rule-based + Gemini AI approach.

## ✨ Features

- Prompt quality scoring
- Hybrid scoring engine
- Clarity analysis
- Context analysis
- Specificity analysis
- Word and sentence analysis
- Role detection
- Constraint detection
- Output format detection
- Example detection
- Missing information detection
- AI-powered prompt optimization
- Multiple prompt styles
- Prompt history
- SQLite database
- Streamlit interface
